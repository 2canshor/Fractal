# System Review

Use the deterministic System Review runtime for the snapshot and stage order. Stop if the Project does not contain primary-user Project Completion.

Work through Project Assessment, Issue Scan, Project Patterns, Cross-Project Patterns, Reversal Check, Cause Research, Reconciliation, Improvement Options, Expected Effect, Local Effect, Global Effect, Two-Sided Review, Final Assessment, and Result. Link each conclusion to observed evidence.

Keep External Research and Internal Review independent until reconciliation. When a consequential warrant exists, keep Case For and Case Against independent as well. Select the lightest evaluated agent that has the required capabilities; branches supply evidence, not the final decision.

Consider deletion, shortening, merging, and simplification before addition. `No Change` is a valid result. Only the Main Agent makes the final suggestion. A proposal remains inactive after approval until an approved System Version passes build, adapter, migration, and restore gates.
