# Writing Authenticity

Identify whose voice the text represents. Use an accepted private profile only when the user asks for that person's voice and the profile passes the Personalisation Relevance Test. Keep third-party and reference material in its own register.

Remove inflated significance, promotional filler, vague attribution, repetitive rhetorical frames, uniform sentence rhythm, canned openings and closings, and formatting used instead of structure. In colloquial language, keep the chosen dialect consistent. Do not replace one fixed banned-word list with another mechanical style.

Preserve claims, uncertainty, citations, and intent. Flag a factual issue instead of silently rewriting it. Compare the result with the source for omissions and authorship drift before returning it.
