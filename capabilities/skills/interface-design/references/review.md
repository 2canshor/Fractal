# Interface Review

Inspect the actual rendered surface and its source. Check keyboard operation, focus visibility, semantic structure, labels, contrast, resizing, touch targets, loading and error feedback, reduced motion, responsive layout, and content clarity where applicable.

Use current primary standards for any compliance claim. Report observed defects with the smallest useful source location and explain the user impact. Distinguish local visual evidence from runtime, backend, authentication, deployment, and device evidence. Re-test the real interaction after a fix; do not close a finding from source inspection alone.
