# Interface Direction

State a short design read covering product surface, audience, purpose, and intended character. Derive typography, colour, spacing, motion, and content hierarchy from that read and from existing assets rather than a default trend.

Use real content where available. Make structural decoration carry meaning. Keep motion purposeful and respect reduced-motion settings. Match implementation complexity to the chosen direction. Before building, compare the direction with the brief and remove any choice that would be equally likely for an unrelated product.

Preserve established visual identity unless the approved task includes changing it. A platform convention is a constraint, not a reason to copy a platform-specific folder or tool architecture.
